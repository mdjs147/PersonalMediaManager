# Guard discipline

Every generic control has an implementation, real invocation point and positive/negative output. A script or hook existing does not prove invocation. Exercise first-write, recovery and final delivery separately; deliberately remove the gate call and confirm the acceptance test turns red. Restore exact bytes and check the diff.

No generic control may be removed because the product stack is absent. Technical-only .NET/IIS/SQL Server checks have no current object, while verification, language consistency, encoding integrity, task scope, independent review and secret protection receive current Python/Git/public-document replacements.

Source tool assets remain byte-identical to pinned Git blobs. Context is reviewed, never automatically approved from inspect. Every changed implementation invalidates its bound control evidence. Final candidate changes invalidate final sidecar evidence.

Public-tree audit covers all tracked and candidate input files, not only the patch. Keep raw private documents, personal descriptions, credentials, databases, models, binaries and old implementation out. Do not delete old local work to manufacture an empty history.
