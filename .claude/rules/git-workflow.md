# Plan-first successor and stage-only delivery

Use the exact origin/default/stage observations. Main is the default; dot/pmm-rebuild-20261005-gates is the only approved integration target. Task branches are author worktrees, not alternate publication targets.

A plan publication is an additive, independently reviewed plain-document commit, with explicit previous-stage SHA and exact publication paths. Export the controller and its Python dependencies from that old stage into an isolated trusted directory, then call its plan entry against the candidate worktree. Candidate edits cannot change the controller that accepts their own scope. Keep the plan review outside the candidate to avoid a self-referential commit hash. The exact review binding includes candidate, tree, base and diff. Observe the remote immediately before a non-force connector update and immediately after. Non-CAS provider races cannot be called atomic; any observed drift stops dependent work.

Activation is a separate metadata/context/evidence candidate. Its plan must already be on the stage; implementation cannot ride along. Explicitly assign actual actor/execution and bounded legitimate handoff executions, prove predecessor candidate acceptance, review the current environment and all generic controls, and obtain independent activation review. Planned cards alone cannot activate themselves. Publish/read back activation before ordinary first-write. GOV002's initial one-time repair was instead admitted by the separately reviewed exact five-file plan and external fixed-base checks; that bootstrap is not evidence that the new ordinary lifecycle had already worked.

First-write/recovery require clean owned worktrees; commit requires no unstaged changes. Scope is read from immutable Git plan objects, with frozen card/applicability bytes checked both locally and on the actual stage. Pending readiness allows only an explicitly published governance repair, never foundation or business. Resume may use a different execution only if already listed in the independently reviewed activation; perform the actual gate in its actual owned worktree.

Final acceptance requires fresh controls/context, full failure-sensitive verification, semantic public-tree review and independent candidate review. Changed candidate, context, output or implementation invalidates its bound evidence. Final sidecars remain outside the candidate. Only the accepted task may integrate into the stage; no main, force push, release, deployment, real accounts or security changes.

## Registered candidate preparation

Keep hooks enabled. Set PMM_OPERATION=plan or activate, PMM_OLD_SHA to the freshly observed stage, and PMM_TRUSTED_CONTROLLER to scripts/pmm_workflow.py exported with all CORE dependencies from that exact old Git tree. A plan also sets PMM_PLAN. The registered pre-commit calls prepare-plan/prepare-activation against the index before creating a candidate; scope, ownership, staged bytes and independent state activation review are checked. After candidate creation, obtain a separate candidate-bound PMM_PUBLICATION_REVIEW. The registered pre-push calls the trusted plan/activate entry with actual outgoing refs/SHAs/remote. Missing mode data or unknown mode rejects. The default implementation path remains commit plus git-target/deliver.

Same-task handoff is a reviewed activation metadata update: keep immutable plan, task scope, phase, construction base and previous participant history, add the actual replacement execution, publish/read back and recover in its real worktree. It is not actor impersonation or a new implementation acceptance.

DEV001 activation checks SDK/current context and all governance suites; before source exists, foundation build/product checks are explicitly NOT-RUN. Implementation delivery then requires tracked dependency lock files, restore from the explicit official NuGet feed in locked mode, build/test with nonempty tests, and tests/foundation/verify_foundation.py proving an inert isolated host. CI provisions SDK10 for the foundation phase; generated build assets are never committed.
