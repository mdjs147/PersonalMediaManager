# 标题变体与来源编号候选

本页说明标题变体、技术尾和裸尾数的规则边界；模型实验输入与效果另行记录。

## 标题变体

仅扩展规则侧 `RuleNamingEvidence`，新增 `TitleVariants`。每个变体包含：

- `Title`：保留原字形的完整名称片段；只沿现有分隔符归一化处理
- `ScriptHint`：`Cjk`、`Latin`、`Mixed` 或尚未分类的 `Other`，与自然语言分开
- `Language`：无独立证据时为空；拉丁脚本不等于英语，`CHT` 字幕标记不等于作品名语言
- `Source` / `SegmentIndex`：完整文件名或原始相对目录段的来源
- `Start` / `Length` / `Token`：UTF-16 原文区间；必须能从所指原输入逐字取回 Token
- `AliasOf`：同处命名的候选关联，不能解释为已验证译名或已确认同一作品

只有主标题确实拆成两个有原文区间的完整片段、且恰有一个含 CJK 片段与一个纯拉丁片段时，才优先采用完整 CJK 片段作为主名。该规范化也适用于动态用户规则捕获的标题；同语法动态规则的精确正则已有合成回归测试，不能因 `MatchedRuleId` 非空绕开。粘连的 CJK 与拉丁后缀仍是完整片段，不能为追求纯中文而切成过宽的系列名称。独立罗马数字是编号线索，不能被误当完整外语名称分走。组合原文仍保存在 `OriginalTitle`，候选关系和原文区间保存在变体中。

合成命名示例 `[Example-Subs] GRAND BLUE 碧藍之海 3 - 01 [720P][WEB-DL][AAC AVC][CHT].mp4` 保留繁体主名 `碧藍之海` 与独立 `GRAND BLUE` 候选。此合成输入只复用经核实的公开编号映射，不新增作品词典或语言推断。当前没有可靠的既有繁简转换器，因此不生成简体别名、不安装新转换器。

合成命名示例 `测试机甲SEEDFREEDOM.Example.Mech.Seed.Freedom.2030.720p.WEB-DL.AAC.H264-ExampleGroup.mkv` 保留主名 `测试机甲SEEDFREEDOM`；拉丁候选的 Token 保留点号，展示候选可使用空格。不得产生 `测试机甲` 或 `SEEDFREEDOM` 这种被截断的候选。

## 标题中的小数标点

完整原文标题中的单个小数编号可能有作品或发行版本语义。主名既有归一化不变，但从已经定位的精确 `TitleVariants.Token` 新增优先检索词，保留小数点；例如标题中 `2.22` 后仍有完整副标题时，不将检索词写成 `2 22`。原文区间继续可核查。

小数集标记、版本前缀（包括点号/冒号分隔）、声道等技术尾、整数与小数混合的合集范围、只有尾部裸小数、拒绝过集号解释的输入均不走此增量。即使该检索词只搜得一个高分候选，也保留首查候选与新增候选的有界 `(type,id)` 并集、保存规则字段并转待确认，不能据此自动断言作品身份或发行版本映射。

## 圆括号技术尾

合成命名示例为 `[Example-Subs] Example Chronicle - 01 (CR 1920x1080 AVC AAC MKV) [0A1B2C3D].mkv`，目录为 `迅雷下载`。

新增规则沿用已有 `标题 - 单集号` 语法，只在后面的圆括号及方括号内容均能逐词确认为已知技术参数时接受；尾块的大小、编码、音频、容器和校验码逐项清除后必须为空。此例可得到 `Example Chronicle` 与来源单集 `1`，季号与年份保持未知。普通副标题、混入的剧情文字、小数集、多集范围与四位年份不能走此新路径。强制电影规则保持原语义。

## 父目录佐证的裸尾数

合成命名示例为 `Example Chronicle 21 [WEB-DL 1280x720 AVC x264 8bit ASSx1].mkv`，直接父目录为 `Example Chronicle [WEB-DL 1280x720 AVC x264 8bit]`。

该形态与 `Toy Story 3 [1080p].mkv` 位于 `Toy Story [1080p]` 目录不可仅靠结构区分。处理保持保守：

- 主标题仍保留 `Example Chronicle 21`，不声称已经正确解析集号
- 完整同名父目录只提供 `Example Chronicle` 搜索候选
- `NumberingCandidate` 记录原文件中的 `21` 及其完整原文区间
- `Uncertainties` 增加 `EpisodeOrSequelNumber`
- 不向 `Episode` 写入候选、不据此改为 TV、不补季号；续作主标题不删编号

所有判断只依据原始输入与现有源码，没有读取参考答案或密封结果，没有硬编码这些作品的正确答案。

## 验证范围

新增测试覆盖完整繁体主名、Latin 不等于英语、源区间逐字验证、目录段索引、混合粘连主名、技术圆括号正反例、未知副标题、小数与范围、裸尾数与续作同形歧义、四位年份以及用户强制电影规则。已调整原有双语组合标题的断言以符合完整 CJK 主名优先的新行为。

## 全量规则回放后的证据边界修正

独立规则回放发现，原文区间能逐字对应并不能证明片段是作品名。第一版新增元数据把 `HD官网中英双字` 提升为主名，并将发行组、跨方括号片段和通用下载目录记为标题变体。

后续独立候选只收紧新增标题证据和搜索别名入口：

- 整段由已知技术、字幕和发行描述组成，且含技术或字幕锚点时，不生成作品变体或搜索别名；`官网` 等字样嵌入正常标题时保留
- 还含方括号的组块或跨块片段不声明为独立译名；原始规则主名不因这一过滤被删除或擅自清洗，干净的既有搜索候选仍可保留
- 通用目录（包括 `迅雷下载`、`夸克下载`）不生成作品变体或别名；这不等于已经修复所有旧规则从目录回退得到的未知主名
- `Up`、`IT`、`Pi` 等短名称不按长度丢弃；没有新增翻译、季集、年份或媒体类型推断

因此未知发布标签样本不再依靠发行组与日文标题的“伪双语”关系自动选主名；未解析的多层方括号结构也不再产生有精确区间却语义错误的译名。这是有意保守的证据过滤，尚未实现完整的方括号发布结构解析。原始私有审计与模型实验保留不变，公开测试与本文仅使用合成输入。
