# 人工确认辅助

## 作品候选

人工确认页优先显示已归档媒体库中的作品：同目录上下文、标题/原名或别名匹配在前，最近更新的未完结剧作为备选。每张卡片显示来源。库内备选与 TMDB 解析/手动搜索候选都需要用户点选，不能用最近更新顺序代替身份确认。

库内加载失败可重试，不影响继续搜索 TMDB。关闭、切换作品组或发出新查询后，旧请求不得覆盖当前页面。

## 季集提取与批量填写

只作用于勾选文件，先生成预览，再点击“确认应用可用项到表单”，最后另行确认归档。生成预览不落库、不调用远程 AI、不移动文件。

- 本地规则提取：使用服务端同一规则引擎，逐项显示证据或错误；没有证据时留空
- 统一季号：仅改变季字段，默认保留已有值
- 连续编号：按文件名自然排序，从指定起始集号与正整数步长生成；选中范围内每个文件占一个位置，即使其已有集号被保留
- 保留已有字段：默认开启；冲突证据会显示保留值与建议值
- 多个解析标题需先明确核对同一作品或缩小范围；跨季连续编号、正片覆盖特别篇、合并多集区间、重复集或重叠区间不会静默应用
- 预览后修改作品、选中范围、表单或选项，必须重新预览
- 取消只丢弃预览；不自动保存或归档

缺季号不在前端自动补第 1 季。所有选中剧集都必须具备有效且互不重叠的季集信息，才能确认归档。

## TMDB 季目录与累计集号

选择作品或核对目标季时刷新 TMDB 元数据，显示作品/季目录缓存时间和刷新失败提示。刷新失败时旧缓存仅供核对，不代表资料已更新。

跨季累计编号是独立入口，必须勾选“这些是跨季累计编号”，选择第 2 季及以后的目标季，再请求服务端映射预览。明确的 SxxEyy、特别篇、跨季区间或不完整目录不能静默转换。应用映射时保存服务端令牌和原始累计编号，确认归档时由服务端再次校验。手工再修改季集或作品会清除令牌，作为新的人工决定处理。

## 提交与诊断

确认按小批次串行提交，二次确认前即加锁，重复点击不会重复提交。成功文件从当前页面移除；逐项失败保留在原页并展示原因。连接中断时停止后续批次，要求刷新核对服务器状态，不能自动重复提交不确定项。

归档成功但 TMDB 刷新失败单独显示告警，不把已成功项伪装为确认失败。人工决定来源包含表单、库内选择、规则提取、批填、累计映射；记录旧/新值，但不作为自动解析的正确答案。
