# 本地模型辅助

本版为可关闭的检索辅助。默认 `Disabled`，不会在应用启动时下载模型、启动推理进程或改变既有 AI 提供商。入口是「解析设置 → 本地模型」。

## 运行准备

1. 从 [llama.cpp 官方项目](https://github.com/ggml-org/llama.cpp/tree/master/tools/server) 安装适合本机的近期 `llama-server`。本版没有运行时安装器；支持 Windows、Linux、macOS 的 x64/arm64，具体官方二进制能否在本机运行仍需启动自检。
2. 在设置中填写本机可执行文件的绝对路径。只接受 `llama-server`（Windows 为 `llama-server.exe`），不接受网络路径、额外命令行或自定义服务 URL。
3. 准备固定模型文件。Qwen2.5 0.5B Instruct Q8_0 可从设置页下载，固定到官方仓库 revision、文件大小和 SHA-256，下载成功前校验全部字节。Huihui Qwen2.5 0.5B Instruct abliterated v3 为实验性本地自转 Q8_0，仅允许手动放入下述固定路径、与已验证制品完全一致的文件；没有已核验的官方 GGUF 下载地址，设置页不提供下载按钮。两者都可在现有模型选择中选用，不会自动启用辅助。
4. 显式启动并等待健康检查通过。保存设置、下载模型、启动进程、开启辅助模式是独立操作。更改设置会停止旧进程，需重新启动；退出应用会停止其自行启动的子进程。

服务仅监听 `127.0.0.1`，不开放局域网，不使用 API Key。端口被占用时直接拒绝启动，不连接或停止其他程序。应用仅管理自己持有的进程句柄，通过随机模型别名确认健康响应归属。

线程数、上下文、输出长度和请求时间均有上限。内存保护每秒检查子进程工作集，超限停止进程；它不是操作系统级硬性内存配额，短时峰值可能超过设置。每次启动前重新校验模型 SHA-256，文件存在或大小一致不等于已经通过完整校验。

### 实验 v3 本地文件

- 源权重：[huihui-ai/Qwen2.5-0.5B-Instruct-abliterated-v3 的固定提交](https://huggingface.co/huihui-ai/Qwen2.5-0.5B-Instruct-abliterated-v3/tree/3dee99dac7c99318ed2b4e9932bfbbac060fb024)，revision `3dee99dac7c99318ed2b4e9932bfbbac060fb024`
- 转换工具：官方 llama.cpp revision `13b4d7135a6351f81e1eccf6361a4eafd50350eb`，本地转换为 Q8_0；这是自转制品，不是作者发布的 GGUF
- 固定文件名：`huihui-qwen2.5-0.5b-v3-q8_0.gguf`
- 固定目标：`<AppPaths.Root>/local-ai-models/huihui-qwen2.5-0.5b-v3-q8_0.gguf`；设置页显示当前 PMM 服务所在电脑的完整实际路径
- 大小：`531068416` 字节
- SHA-256：`15c5d19fd98774df4fa4df949e4f8cc7c8b32ff366895e23d69f9222b4082816`

先停止本地服务，再将符合上述大小与哈希的完整文件放入固定目标，点击“刷新状态”，选择模型并保存，最后单独启动。相同名称、同一源 revision 或相同量化类型都不能替代字节校验；不同转换结果只要哈希不同就不能启动。本版没有上传或任意路径导入端点，也不接受模型文件或目标目录的符号链接。

目录的 `CanVerify` 与 `CanDownload` 独立：v3 可校验、不可下载。设置页的“大小匹配”只代表存在匹配大小的文件，完整 SHA-256 在每次启动前复验。缺失、大小不符或哈希不符时拒绝启动，保留原文件和其他模型，解析按既有流程回退，不会删除用户来源文件。即使模式仍为 `Disabled`，也可以显式启动验证服务健康；这不会开启解析辅助。

## 介入时机与数据保护

- 关闭：不生成本地模型建议
- 规则前：先从原始文件名和直接父目录生成原文区间候选，再请模型选择，然后仍独立完整运行规则。规则已解决的文件不会因为小模型的不同回答改走人工流程
- 规则后：规则及现有目录查询仍未解决时，才向本地模型请求补充建议

两种模式使用相同的闭集原文区间协议 `source-spans-2-video/index-v1`。输入只有原始 `fileName`、`parentFolderName`（直接父目录）和程序按冻结的 `source_spans.py` 生成的候选列表，不带其他上层目录、绝对路径、历史答案、规则字段、规则置信度或 `ruleHint`。文件名超过 512 个 UTF-16 单元或直接父目录超过 256 个 UTF-16 单元时不调用模型，不静默截断输入。

程序按原文顺序生成最多十二个候选，保留来源、区间、原文字面、生成边界与索引；候选按逐字文本去重。超过十二个或没有候选时直接弃权，不把截断候选池交给模型。候选构造包含技术后缀、明确季集、编号替代和可见语言边界等规则；这是程序候选生成能力，不能记作模型准确率收益。Python 冻结协议按 Unicode 码点计偏移，PMM 内部来源区间按 UTF-16 计偏移，传入模型时对应转换；包含补充平面字母或数字等无法保证冻结正则语义等价的输入，也保守弃权。

模型输出只能是 `{"index":0}` 这类允许索引，或 `{"index":null}`；没有自由填写的标题、证据、别名或翻译字段。推理固定 `temperature=0`、本次最大输出 32 tokens，并指定 `response_format.type=json_schema`，schema 名为 `literal_span_selection`、`strict=true`。schema 仅包含必填的 `index`，取值枚举为 `null` 与本次候选索引 `0..n-1`，`additionalProperties=false`。没有候选时不发请求。

返回后，程序再次拒绝重复 JSON 键、额外字段、截断、格式错误、非整数或越界索引，并用所选原文区间还原唯一检索词，复查区间与原文逐字一致。模型不能生成 TMDB ID、年份、类型、季集或置信度。`null` 表示弃权；字面正确只证明检索词来源存在，不证明作品身份正确。

已知噪声会被进一步过滤；本地模型辅助对长度不超过三个字符的纯 ASCII 候选（包括 Up、IT、Pi）保守弃权，既有规则的短标题解析保持原样。噪声过滤仍不完整，合成负例中仍有误选，不能把实验结果描述为准确率获胜或可自动采用。因此辅助默认关闭，模型选择始终只是待确认的检索建议。

## 查询预算与确认

每次辅助最多采用一个原文检索词，至多查一次 TV 和一次 movie，共最多两个新增逻辑搜索。已执行的相同查询按标题、类型、年份和语言参数去重；同名的 TV 搜索不能省略尚未执行的 movie 搜索。

这些搜索串行共享一个十五秒总期限。使用既有 TMDB 搜索缓存、限流与 HTTP 退避，不另开绕过流程的网络客户端；固定同一语言且不按年份过滤，避免搜索服务隐式扩展语言/年份组合。既有 HTTP 客户端每次逻辑搜索最多四次尝试，因此理论物理上限是八次，并仍受同一个总期限和取消令牌约束。缓存命中、空结果、失败、超时分别记录；错误后停止剩余查询。

新候选按 `(mediaType, id)` 去重，不按数字 ID 单独去重，不按热门程度或模型自评分自动绑定。建议命中也进入待确认：保留原规则字段供审核页预填，不绑定新的 TMDB 身份、不改写已有绑定，也不执行归档。为了不让先到的 TV 列表挤掉 movie 解释，本轮本地审核快照保留原入口最多二十条候选及两个新查询各最多五十条，去重前至多一百二十条。`ProcessFileService` 的三百二十条内部序列化上限保留以兼容旧内部调用和测试替身，不代表本轮会执行六次搜索。普通旧入口的二十条限制不变。

建议为空或运行时、下载、推理、检索故障时，继续原规则流程，不清空已有字段或候选。用户主动取消整个文件处理时立即传播取消，不当作普通失败继续调用。既有手动绑定、季集目录、版本编排和同名身份守护继续执行。

## 缓存与审计

本地建议缓存只在内存中保留十分钟，最多一百二十八项。键包含模型、设置、协议版本、模式、实际模型输入和直接父目录在原目录段中的索引；失败、取消和无效 JSON 不缓存。缓存命中明确标记，不计为新推理请求。解析时间线记录原始输入、规则快照、实际提供的候选池、模型响应、选中来源区间、拒绝原因、查询记录与待核验状态；审计中的规则快照不等于发送给模型的输入。

设置保存在现有 `System_Setting` KV 中，没有数据库 schema 迁移。专用设置键不能通过通用 KV 端点绕过校验。更新设置、启动和停止共享运行时互斥边界，防止保存过程中并发启动旧配置。

## 版本与验收

本地开发目标：产品 `0.3.0 → 0.4.0`，唯一人工版本源为 `Directory.Build.props:PmmProductVersion`；后端与前端版本元数据自动派生。数据库使用现有设置 KV，本轮无新增 EF migration，不维护独立 schema SemVer。版本写入不代表已经发版或部署；实际发布前按 [发版流程](发版流程.md) 核对产品版本、commit、迁移状态和运行前置要求。

模型实验只支持将小模型用于可选建议，尚未证明可以自动覆盖正确规则或自动绑定身份；本版没有这类开关。真实平台启停、浏览器交互、单元与集成测试的执行结果需随最终验证记录列明，不能用 Linux 验证代替 Windows/macOS 验收。
