# Current domain boundary

DEV001 supplied the accepted fresh offline Foundation/Web scaffold and isolated test support. Its host exposes only the inert Razor root and foundation health route. No Catalog domain, production database or business HTTP/MCP operation is implemented by GOV003.

The development-offline-domain / offline-domain phase permits only Catalog source paths explicitly granted by a later published and independently activated card. Foundation/Web source expansion, real media or old databases, network integrations, credentials and production business remain excluded; business_allowed stays false. A local test calling an offline core is not production-route or platform acceptance. Confirmed product directions remain in docs/requirements/retained-decisions.md; no old implementation or passing count is inherited.
