# PMM readiness tool contract

The validator, schema, templates and synthetic regression file are byte-preserved from the recorded fixed source. Python standard library and Git only. The executable is read-only.

inspect observes the current repository/environment without approving it. check-context requires ready status, genuine independent context review, fixed navigation and bound positive/negative control evidence. deliver additionally binds an explicit base, exact current candidate/tree/diff, clean tracked tree, scope and independent sidecar test/review reports. Declared sidecars are the only allowed untracked delivery inputs.

The source regression suite creates synthetic repositories and does not prove current PMM readiness or product acceptance. Actual PMM call-site acceptance is separate. The project's default branch is origin/main, while the delivery base_ref is origin/dot/pmm-rebuild-20261005-gates. No scope is silently expanded.

Source update discovery and runtime/live-remote probes are separate from the validator, which does not network or probe language runtime versions. Distinct actor labels are declarations, not signed identities. Hooks and repository-local scripts can be bypassed; remote protection is not claimed.
