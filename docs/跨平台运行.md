# Linux / macOS 运行与验证

## 入口与支持边界

- Windows：原 Launcher（WinForms NotifyIcon）保留
- Linux：`PersonalMediaManager.Server`，控制台/WebUI，无托盘依赖
- macOS：同一 Server 默认启动相邻 `PersonalMediaManager.MacTray`（Swift/AppKit），显示运行状态、打开 WebUI、退出。缺少组件报错，不静默退化。明确无桌面运行时加 `--headless`
- Host 的 `PmmBootstrap.StartAsync` 统一迁移、自愈、种子、后台任务启动顺序
- 当前 macOS 代码与构建门禁不等于实机验收；需按 MacTray/README 完成原生菜单及关闭验证。没有签名、公证、自动登录启动或自动防火墙改动
- 正式 Release 工作流仍保留 Windows 产物；可移植包通过下述脚本本地构建，未自动公开发布

## 构建

要求 .NET 10 SDK、Node 22+、npm；macOS 完整包还需 Xcode Command Line Tools。

```sh
npm --prefix src/PersonalMediaManager.Frontend run version:check
npm --prefix src/PersonalMediaManager.Frontend ci
dotnet build src/PersonalMediaManager.Server -c Release -m:1
bash scripts/test-portable.sh
bash scripts/smoke-portable.sh
bash scripts/build-portable.sh linux-x64
# 在 Mac 上：bash scripts/build-portable.sh osx-arm64
```

产品版本只维护 `Directory.Build.props:PmmProductVersion`；修改后先运行 `npm --prefix src/PersonalMediaManager.Frontend run version:sync` 更新 npm 兼容元数据。打包脚本和 CI 在安装依赖前执行只读 `version:check`，发现漂移会停止。数据库使用 EF migration 状态，不单独编号。

完整包目录为 `artifacts/publish/<rid>`，保留整个目录；不能只复制 Server 文件。支持脚本 RID：linux-x64、linux-arm64、osx-x64、osx-arm64；交叉发布不是对应架构的运行验证。macOS helper 必须与 Server 相邻。Windows 完整解决方案构建继续使用原流程。

## 启动与数据

```sh
./PersonalMediaManager.Server --data-dir /absolute/private/pmm --port 7288
# macOS 无桌面服务：追加 --headless
```

- `--data-dir` 优先于 `PMM_DATA_DIR`；不指定使用平台默认位置
- Linux：绝对 `XDG_DATA_HOME` 下的 PersonalMediaManager，否则 `~/.local/share/PersonalMediaManager`
- macOS：`~/Library/Application Support/PersonalMediaManager`
- 旧非 Windows 试验数据不会自动移动；用 `--data-dir` 明确选择旧目录，并确保私有权限。迁移需同时保留数据库和 keys，不能只搬数据库
- Unix 数据根与敏感子目录要求 0700，密钥文件 0600。拒绝不安全的既有显式目录，不替用户修改任意目录的权限。备份含密钥，必须按敏感文件保管
- 同一数据根仅允许一个 Server，锁持有到服务退出。Server 不接受 `ConnectionStrings:Default` 外置库覆盖，请用数据根选择数据库，避免跨根指向同库绕开锁
- Windows Launcher 与 Server 不应同时对同一 Windows 数据根运行；Windows 日常使用 Launcher

## 网络与停止

Server 默认仅监听 127.0.0.1，固定端口被占用直接失败。`--bind <IP>` / `Web__BindAddress` 可显式改变监听地址；暴露局域网前应完成管理员设置并配置网络保护。命令行优先于环境变量、local.json 和出厂配置。Windows Launcher 保留原端口回退和监听习惯。

macOS 菜单访问回环地址，因此桌面模式应使用 127.0.0.1 或 0.0.0.0；仅监听其他地址时使用 headless。Ctrl+C / SIGTERM / 菜单退出走正常宿主停止；辅助进程意外退出也停止 Server，避免看不见的常驻进程。

## 验收

`test-portable.sh` 串行运行五个非 Windows 测试项目，排除固定墙钟性能基线。`smoke-portable.sh` 仅用临时空库，覆盖两次启动、health、内嵌 HTML/JS、重复实例拒绝、真实端口冲突、权限、SIGTERM 与端口释放，不调用真实媒体提供商。设置 `PMM_SERVER_EXECUTABLE` 可验证自包含发布文件。Host 测试夹具默认在进程内拒绝外部 HTTP；需协议响应的用例显式使用内存 handler，不能调用任意公网测试域名。

PR CI 保留 Windows job，增加 Ubuntu/macOS 可移植 job。macOS CI 编译 helper 不替代菜单点击实测。还需实际目标平台验证监控/重命名事件、网络盘、FFmpeg 可执行权限、大小写敏感/不敏感 APFS、备份恢复与升级回退。未验证项目不得写成已支持全部桌面功能。
