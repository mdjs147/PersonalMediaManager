# 解析证据与 AI 编排

规则提取、模型声明、字段守护与 TMDB 核验是不同阶段。原始文件名和有限目录信息始终保留；后一个阶段的修正不能冒称原模型回答正确。

## 规则与原文

- 混排标题只在明确分隔处拆成完整片段，粘连副标和续作数字保留。脚本类别不等于英语、日语或中文繁简语种
- 目录尾部集数范围须有文件当前集号独立佐证且位于范围内，才从作品标题中分离；目录范围不能直接变成文件的结束集号
- 裸尾数不能单靠形状判作季或集；没有独立证据时保留原名与编号候选
- 分季副标题映射限定完整系列身份和可核查目录来源，显式季号冲突转待确认
- Remaster、Special Edition 等版本信息保留；去版本名称只是第二检索词，不证明同一发行版或集序映射
- 分辨率、画面宽高、完整日期和目录日期不能代替作品首播年份

标题变体包含原文 Token、UTF-16 区间和来源段索引。技术字幕描述、发行组、通用下载目录和未解析方括号结构不能凭“区间真实”就成为已确认译名。具体边界见 [标题变体与来源编号](规则候选-标题变体与来源编号.md) 和 [目录范围标题](规则候选-目录范围标题边界.md)。

## 现有供应商契约

既有 AI 供应商入口默认保留 SchemaVersion=1，v1 请求投影保留原有字段。显式 v2 支持紧凑/扩展输出、系列与分季标题、版本标记、标题变体、来源证据、冲突与不确定字段。

响应解析先检查重复 JSON 键和原始字段形态，再应用锁定值与规范化。重复键按每个对象作用域判断，不将不同嵌套对象中的同名字段误作重复。错误或未知字段记录路径、预期/实际类型和是否阻断，不能静默丢弃后把整答计成干净成功。confidence 必须是有限的 0–1 数值，不把 100 猜成百分制。

movie 声明若与可信季集或原文明确季集标记冲突，必须弃权并保留原有季集用于核对，不能先按 movie 清空正确规则字段。年份、技术词和弱规则类型不单独证明作品属于电影或剧集。一般标题中的 The Movie 也不能独立作为电影证明。

`RequiresIdentityVerification` 与 `CanSearchForIdentity` 表示可用于核验的部分结果；它们与最终可采用身份分开。未知类型不默认为 tv。经过字段守护仍不等于允许归档：同名、媒体类型、季集目录、版本编排等守护必须继续执行。

## 本地小模型的独立建议路径

本地模型管理和 Disabled / BeforeRules / AfterRules 设置已经接入，默认关闭；详见 [本地模型辅助](本地模型辅助.md)。它独立于既有云 AI 提供商设置，不改变后者的已保存启用状态。

程序依冻结的 source-spans-2-video 算法生成至多十二个原文区间，模型只能返回其中一个 index 或 null。输出由 JSON schema 闭集约束，程序另行检查键、整数类型、范围与来源，逐字还原一个检索假设。超过候选上限或输入长度限制时不调用模型。它不能自由生成标题或译名；模型输入不带规则 hint。原规则字段不写入模型可覆盖的输出 DTO，模型也不能返回可直接采用的 TMDB ID、年份、类型或季集。候选检索遵守总预算、去重、缓存、限流、总超时和取消；新命中保存至待确认列表，不进入旧 AI 自动采用通路。空结果与失败继续原流程，不清空已有规则结果。

## TMDB 核验

同名的不同 `(mediaType, id)` 不可仅靠热度、语言或综合分差消歧；候选主名和原名交叉比较，原文年份能唯一排除歧义时才形成独立证据。

单季补 S01 必须取得同一 typed ID 的详情，且总季数、唯一正季号、正集数及文件集号范围一致。只有汇总季数、缺季目录、仅特别季、唯一正季为 S02、集号越界或存在版本/分季歧义时不能补 S01。

提取类型与最终 TMDB 类型分别记在核验轨迹中。强制用户绑定保留其显式权限；普通候选不能静默覆盖来源季集或显式类型冲突。来源集序与正典集序不同的发行版还需要可靠的剧集组或人工映射。

## 验证与发布

规则、模型、提示词、结构、守护和目录核验各自记录变更因素。实验强制逐条调用不等于生产默认行为；不能把规则恢复值算作模型新增，也不能把字段变化数算作作品身份正确率。

产品代码回归、可运行验证和模型效果分别报告。冻结实验输入、响应与旧运行库保留在独立评测资料中，不随当前代码改写。当前统一产品版本为 `0.4.0`。合并、发布和部署前须按 [发版流程](发版流程.md) 核对唯一产品版本、commit、EF migration 状态及运行前置条件，不再分别升前端、后端或数据库版本。
