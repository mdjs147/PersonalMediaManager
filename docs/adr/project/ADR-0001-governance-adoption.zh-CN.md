# ADR-0001 治理接入与产品开工分离

> 状态说明（2026-10-06）：重建已暂停，等待基线仓库就绪。本文提到的源码、测试、构建配置、hooks、CI、任务卡与证据已从本分支移除，清空前状态见 tag `archive/pmm-rebuild-pre-clear-20261006`。本文仅作为设计输入保留。

状态：生效于治理接入范围

采用固定通用基线的只读readiness工具，并为公开PMM重写自足规则。九项通用控制目标不裁掉；私有个人描述及来源项目部署约束不公开。技术层没有当前对象时保留未来适用性复核义务，其通用验证、写作和编码完整性义务立即由当前工具承接。

默认main只读；交付基准与允许合入目标为独立dot阶段。任务卡先发布，独立任务分支施工，验收和独立审查后才集成推送。ready只表示当前治理接入满足记录和现场契约，不能解锁业务写入；phase、产品配置或技术对象变化触发复核。

独立审查和真实执行记录不是由JSON标签认证的身份；本地hook可绕过，CI不追溯防止本地写入，远端保护不作未经核验的承诺。最终候选证据采用树外sidecar避免自引用。
