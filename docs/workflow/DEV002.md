## 中文权威范围

从零实现最小闭环：人工创建本地Movie/Series → 在全新隔离SQLite保存显式季集及覆盖成员 → 通过独立连接一致回读/列表 → 纯内存预览人工编号。无TMDB也能建作品；同名作品用不同WorkId。只实现works.create_local/get/list、works.coverage_read/save、recognition.numbering_preview的离线核心子集，不能据此把完整UI/HTTP/MCP能力或219项业务标为已验收。旧实现、测试、完成数不采用；旧contracts仅作登记过的只读设计输入。

领域和行为以[冻结合同](../requirements/dev002/contracts.zh-CN.md)为准：单Series一个显式manual编号体系；季号是非负Int32，只有集号使用精确十进制文本；保留原文和规范键。覆盖为非空显式有序成员集合，不填补间隙、不从首尾推区间，不猜累计编号、特别篇、资源存在性或完成度分母。CreateWork和ReplaceManualCatalog两类写命令带非空RequestId，后者要求ExpectedRevision；引用约束、CAS、状态和成功receipt在同一事务内完成。

持久化只暴露自己创建唯一新临时库的CreateFresh()，不得接收路径或connection string，不打开旧/真实媒体库或备份。每个session独立真实连接；快照读取在单一read transaction中保持revision与子集一致。预览绑定给定snapshot的Work/NumberingSystem/Revision，仅返回显式映射与问题，不读取store，不改变snapshot、库、receipt或revision，也不声明该snapshot仍是实时最新；没有预览采用入口。
